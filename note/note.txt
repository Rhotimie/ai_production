Terraform is a robust tool for managing infrastructure as code (IaC). 

Infrastructure as Code (IaC): Managing infrastructure through code, allowing for automation and version control.
Terraform: A popular IaC tool that works across cloud providers such as AWS, GCP, and Azure.
Key Terminology:
    Provider: Cloud vendors Terraform works with (e.g., AWS).
    Variable: Parameters controlling deployments.
    Resource: Building blocks of infrastructure (e.g., S3 buckets).
    State: Current understanding of the infrastructure by Terraform.
    Output: Deployment results like URLs.
    Workspace: Isolated environments for different states (development, testing, production).
        - Each worspace / environment should have their different IAM users
    Basic Commands: Introduction to essential Terraform commands for infrastructure management like 
        - terraform init, 
        - terraform apply,  
        - terraform destroy 

GitHub Actions for Continuous Deployment of AI Apps: integrating GitHub Actions into the deployment process to automate project builds.
    GitHub Actions to automate deployments with every code push to the repository, enhancing workflow efficiency.
    enabling Continuous Integration/Continuous Deployment (CI/CD). GitHub Actions allow scripts to run automatically 
        in response to events like code pushes.

Workflows and Jobs:
    Workflows are defined using YAML files and consist of sequences of jobs triggered by specific events.
    Jobs are executed on virtual machines within the GitHub environment.
    Versatility of GitHub Actions: GitHub Actions can be used for additional tasks beyond CI/CD, such as generating documentation or code reviews.
    Comparison with Other CI/CD Tools: GitHub Actions demostrates simplicity and seamless integration, unlike other CI/CD platforms like Jenkins 
        that may offer more features but require more configuration.
